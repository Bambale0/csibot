# csibot

Восстановленный Telegram-бот по Ци Мэнь Дунь Цзя (奇门遁甲) и Ба Цзы (八字).

Проект восстановлен по материалам разработки от апреля 2026 года. Исходная локальная папка была /root/csibot; после её удаления код собран заново с сохранением основного пользовательского flow и алгоритма v2.1.

## Что делает бот

Главное меню:

- 🎋 Рассчитать Ба Цзы
- 🔮 Анализ Ци Мэнь
- ⚡ Ба Цзы + Ци Мэнь
- ❓ Помощь

Ци Мэнь:

1. Пользователь отправляет фотографию карты.
2. Вводит один конкретный вопрос.
3. Вводит дату и время события.
4. Указывает долготу и, при необходимости, UTC-смещение.
5. GLM-5.3 Flash только оцифровывает девять дворцов.
6. Бот показывает распознанные символы и ждёт подтверждения пользователя.
7. Только после подтверждения выполняется детерминированный расчёт Хозяина и Гостя.

Формула восстановленного алгоритма:

    Итог = (S_base × K_empty) + W_struct + C_inter

В расчёте сохранены сезонная сила пяти элементов, 12 фаз, Врата, Звёзды и Духи, 旬空 / коэффициент пустоты, критические структуры и взаимодействие элементов дворцов.

## AI API

Используется Нейроныч API:

    https://api.нейроныч.online

Документация:

    https://api.нейроныч.online/guide

Модель по умолчанию:

    glm-5.3-flash

Протокол:

    POST /v1/chat/completions

Для vision карта передаётся как image_url с data URL. Каждый новый POST получает уникальный Idempotency-Key. Автоматических повторов платного POST при неоднозначном timeout/обрыве нет.

temperature намеренно не задаётся: текущая документация GLM рекомендует при первом запросе не передавать temperature/top_p, а glm-5.3-flash работает с always-on thinking. Для reasoning_effort используются только документированные high или max.

## Установка

Требуется Python 3.11+ (рекомендуется 3.12).

    python3 -m venv .venv
    . .venv/bin/activate
    pip install -e '.[dev]'
    cp .env.example .env

Заполнить в .env:

    BOT_TOKEN=...
    NEIRONYCH_API_KEY=...

Запуск:

    python -m csibot.main

или:

    docker compose up -d --build

## Конфиденциальность

Последняя восстановленная версия проекта работала без постоянной БД. Данные анализа хранятся только в памяти процесса и теряются при рестарте. Фото карты преобразуется в data URL и отправляется GLM только для текущего анализа.

Токены и API-ключи не должны попадать в Git; .env игнорируется.

## Важное ограничение восстановления

Математика Ци Мэнь и Ба Цзы восстановлена из исходного проекта. Это не независимая верификация традиционного календарного/астрономического метода. В частности, расчёт Ба Цзы в версии v2.1 использует упрощённый алгоритм, восстановленный из исходников; он не сверялся здесь с профессиональной эфемеридой/календарём солнечных терминов.

Также бот выдаёт интерпретацию традиционной метафизической системы, а не научно подтверждённый прогноз будущего.

При восстановлении исправлен один явный технический дефект старого кода: 值使 теперь начисляется по совпадению Врат, а не Небесного Ствола. Расчёт истинного солнечного времени также использует стандартный меридиан из фактического UTC-смещения вместо жёстко заданных 120°E.
